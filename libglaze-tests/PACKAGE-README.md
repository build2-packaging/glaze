# libglaze-tests - Multi-format serialization, reflection, and RPC C++ library (tests)

This is a `build2` package containing the test suite for the
[`glaze`](https://github.com/stephenberry/glaze) library.
Only a subset of the upstream tests is covered. Most notably, the networking
tests and the tests that require Erlang or C++26 reflection are not built.


## Importable targets

This package exports no targets.


## Configuration variables

This package provides no configuration variables.
